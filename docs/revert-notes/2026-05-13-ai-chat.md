# AML investigator chat panel — 2026-05-13

Adds a streaming AI chat to the canvas. The model (Claude Sonnet 4.6) sees a
pre-computed digest of the graph + locally-derived AML signals on every send,
so the canvas can be expanded/explored while chatting without the model going
stale.

## Files added (delete to revert)

- `src/lib/canvas-digest.ts` — pure `buildCanvasDigest(nodes, edges)` + `hashDigest()`.
- `src/app/api/chat/route.ts` — Next.js route, streams from Anthropic SDK.
- `src/components/AIChatPanel.tsx` — fixed-right side panel UI.

## Files modified

- `src/components/GraphCanvas.tsx` — two lines added:
  - `import AIChatPanel from './AIChatPanel';`
  - `<AIChatPanel nodes={nodes} edges={edges} />` rendered inside `GraphCanvasContent`'s root.

## Package added

- `@anthropic-ai/sdk` — required for the API route.

## Environment

- `ANTHROPIC_API_KEY` must be set on the server (Next.js env). The route 500s with `ANTHROPIC_API_KEY not configured` if missing. Local dev: add to `.env.local`.

## Design decisions

- **Sonnet 4.6, not Opus** — investigative pattern matching over pre-digested data is well within Sonnet's range. Sonnet runs at ~$3/M input, ~$15/M output. Each turn is ~5K input + ~1K output post-cache → ~$0.02. Opus would be ~5× the cost and noticeably slower.
- **Prompt caching on the system prompt** (`cache_control: ephemeral`). The taxonomy/persona doesn't change between turns. After the first turn within 5 min, the ~1.5K system tokens read from cache at ~10% of base price.
- **Digest is computed on every send, not memoized**. Cheap (linear in node count) and guarantees the model never sees stale canvas state. A simple djb2 hash detects whether the canvas has changed since the previous turn; if it has, a one-line `CANVAS_UPDATE_NOTICE` is injected so the model recalibrates without re-explaining the whole graph.
- **Signals computed locally** (shared address clusters, dual-role people, dissolved companies, recently incorporated, overseas jurisdictions). The model spends tokens on *why* a cluster matters in this specific case, not rediscovering it.
- **Inline node-ID citation** — the system prompt instructs the model to cite node IDs in backticks. The panel parses `` `node-id` `` from streamed text and renders each as a clickable chip that calls `setCenter` on the React Flow viewport, closing the loop between chat and canvas.
- **Pin mode** — a pin button in the panel header freezes the digest at its current snapshot. Useful when the user wants to keep discussing the graph as it was before they expand further. Off by default.
- **Canvas stays interactive while chatting** — the panel is a `fixed top-0 right-0 w-[400px]` overlay; the React Flow canvas extends behind it and remains fully pannable/zoomable in the visible portion to its left.

## How to revert

1. `npm uninstall @anthropic-ai/sdk`.
2. Delete the three added files listed above.
3. In `GraphCanvas.tsx`, remove `import AIChatPanel from './AIChatPanel';` and the `<AIChatPanel ... />` line.

## Tuning knobs

- `SYSTEM_PROMPT` in `src/app/api/chat/route.ts` — change the AML taxonomy or response style. Note: editing this invalidates the prompt cache for ~5 min until the new prefix is established.
- `max_tokens` is currently 4096 (plenty for investigator-style findings; raise if responses get truncated).
- Model swap: change `claude-sonnet-4-6` → `claude-haiku-4-5` for cheaper/faster but less nuanced output, or `claude-opus-4-7` for deep multi-hop reasoning over very large canvases.
- `buildCanvasDigest` signals are extensible — add a new key to `DigestSignals` and compute it in the same pass.
